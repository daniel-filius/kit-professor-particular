Kit de Gestão para Professor Particular

Planilha completa (.xlsx) — Agenda + Financeiro + Registro Pedagógico

  • Cadastro de alunos + agenda do mês integrados: cadastre nome, matéria, horário e valor da aula uma vez só; a agenda puxa os dados automaticamente.
  • Painel financeiro automático: veja quanto cada aluno deve (aulas confirmadas × valor combinado), registre pagamentos recebidos e acompanhe o status Pago / Pendente / Atrasado sem fazer conta na mão.
  • Resumo mensal de receita automático: total previsto, total recebido e % recebido calculados sozinhos.
  • Registro pedagógico por aula: anote o conteúdo trabalhado, observações e um nível de domínio (1 a 5) — indicador de evolução por aluno é calculado automaticamente.
  • Pagamento único, sem mensalidade: ao contrário de apps de gestão que cobram por mês, você paga uma vez e usa para sempre.
  • Funciona em Excel, LibreOffice e Google Sheets — computador ou celular.
  • Já vem com 3 alunos de exemplo preenchidos para você entender a lógica antes de colocar seus dados reais.

Perguntas frequentes

Preciso saber fórmulas de Excel?

Não. Você só cadastra os alunos e lança as aulas/pagamentos; os cálculos e status são automáticos.

Funciona no celular?

Sim, abrindo com o app gratuito do Google Sheets.

Quantos alunos cabem?

O modelo vem pronto para até 30 alunos simultâneos — dá para duplicar linhas se precisar de mais.

É integrado com o Superprof/iProfe ou outra plataforma?

Não, é uma planilha independente — funciona com qualquer forma de captar aluno (indicação, plataforma, redes sociais).

Serve para dar aula em grupo (não só individual)?

Serve, mas o modelo foi pensado para controle por aluno — se você dá aula em turma, cadastre a turma como se fosse "um aluno".

Quanto tempo demora para receber o arquivo após o Pix?

A confirmação é manual (ver seção "Como funciona a entrega" acima) — normalmente em poucas horas após o envio do comprovante para danielfilho.workspace@gmail.com.
